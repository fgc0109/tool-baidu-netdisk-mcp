## 版本概览

`v0.1.0` 建立了一个本地优先的 C# 百度网盘工具。它使用百度开放平台公开 API，通过 OAuth 2.0 获取用户授权，并同时提供人工操作使用的 CLI 和模型客户端使用的 MCP Server。

这个版本完成了需求文档中的 R1～R9：从 OAuth、账号查询、文件浏览、下载、上传和管理，一直到 Token 自动刷新、MCP 工具、安全存储及可验证发布。

## 功能内容

### OAuth 与 Token

- 生成带随机 `state` 的百度 OAuth 授权地址；
- 支持 `oob` 授权码和完整回调 URL；
- 使用授权码换取 Access Token 和 Refresh Token；
- 支持手动刷新及 API 调用前自动刷新；
- 同一进程的并发请求只执行一次刷新；
- Refresh Token 失效时返回明确的重新授权提示；
- CLI 的 `show` 命令只显示脱敏后的 Token 状态。

Windows 默认使用 DPAPI `CurrentUser` 加密 Token 文件。首次读取早期明文 Token 文件时会自动迁移为加密格式。默认文件位置为 `%LOCALAPPDATA%\BaiduNetdiskMcp\tokens.json`。

### 账号与文件操作

CLI 提供以下能力：

- `account`、`quota`：查询授权账号和网盘容量；
- `ls`、`search`、`meta`：浏览目录、搜索文件和读取元数据；
- `download`：流式下载、进度、取消、大小与 MD5 校验，默认不覆盖；
- `upload`：4 MiB 分片上传、秒传、缺失分片传输、重试和冲突策略；
- `mkdir`、`copy`、`move`、`rename`、`delete`：应用目录内的文件管理。

写操作严格限制在 `BAIDU_APP_ROOT` 中。删除要求显式确认，覆盖和冲突策略不会隐式放宽。

### MCP Server

MCP Server 通过 `stdio` 启动，不监听端口，不需要 FRP、公网域名或 OAuth 回调服务器。共提供 13 个工具：

- `server_info`、`get_account`、`get_quota`；
- `list_files`、`search_files`、`get_file_metadata`；
- `download_file`、`upload_file`；
- `create_directory`、`copy_files`、`move_files`、`rename_file`、`delete_files`。

服务器支持 `2026-07-28` 的 `server/discover` 流程，并兼容使用 `2025-11-25` `initialize` 流程的客户端。所有工具具有 JSON Schema；标准输出只承载协议帧，诊断日志写入标准错误。

### 安全边界

- Windows Token 默认采用当前用户范围的 DPAPI 加密；
- CLI 和 MCP 错误边界清理 Access Token、Refresh Token、Client Secret、Session Secret 和 Bearer Token；
- `BAIDU_LOCAL_ROOTS` 限制 MCP 可访问的本地上传和下载路径；
- `BAIDU_APP_ROOT` 限制全部网盘写操作；
- Access Token 只发送到允许的百度 HTTPS API、上传和下载域名；
- MCP 返回数量和文本长度具有可配置上限；
- 发布脚本拒绝 Token、`.env`、本地配置、证书及私钥文件，并检查当前环境凭据未嵌入产物。

完整安全模型见 [`docs/security.md`](../security.md)。

## 配置项

| 环境变量 | 是否必需 | 用途 |
| --- | --- | --- |
| `BAIDU_CLIENT_ID` | 是 | 百度应用 API Key |
| `BAIDU_CLIENT_SECRET` | 换取和刷新 Token 时 | 百度应用 Secret Key |
| `BAIDU_REDIRECT_URI` | 否 | 默认 `oob` |
| `BAIDU_OAUTH_SCOPE` | 否 | 默认 `basic netdisk` |
| `BAIDU_TOKEN_FILE` | 否 | 覆盖默认 Token 文件路径 |
| `BAIDU_TOKEN_PROTECTION` | 否 | `auto`、`dpapi` 或 `plain`；Windows 默认 `auto` 使用 DPAPI |
| `BAIDU_APP_ROOT` | 写操作必需 | 百度分配的应用目录，例如 `/apps/应用名` |
| `BAIDU_LOCAL_ROOTS` | MCP 本地文件操作必需 | 本地目录白名单；Windows 使用分号分隔 |
| `BAIDU_MCP_MAX_ITEMS` | 否 | 单次列表或搜索最大返回量，默认且最高为 100 |
| `BAIDU_MCP_MAX_RESPONSE_CHARS` | 否 | MCP 文本响应长度上限，默认 50000 |

## 发布与安装

`scripts/publish-win-x64.ps1` 生成两个未裁剪的单文件、自包含程序：

- `cli/baidu-netdisk.exe`；
- `mcp/baidu-netdisk-mcp.exe`。

压缩包同时包含安装文档、安全说明和带文件 SHA-256 的 `manifest.json`，最终 ZIP 另有独立 `.sha256` 校验文件。目标 Windows x64 电脑不需要预装 .NET 运行时。

安装、OAuth 首次授权及 MCP 客户端配置见 [`docs/installation.md`](../installation.md)。

## 升级与迁移说明

- 从安全存储加入前的工作区升级时，无需手工转换 Token；在原 Windows 用户下首次运行 `show`、API 命令或 MCP Server 会自动迁移旧明文文件。
- DPAPI 密文绑定保存它的 Windows 用户，不适合作为跨电脑迁移格式。换电脑时应复用同一百度应用的 API Key/Secret Key，并重新执行 OAuth `login`。
- 非 Windows 源码运行环境下，`auto` 会使用普通文件存储；应配合严格文件权限、加密磁盘或外部安全存储。

## 当前限制

- 面向单用户、本地运行，不提供远程 HTTP MCP 服务；
- 官方构建产物当前仅为 Windows x64；
- 不模拟百度网页端私有协议，只使用开放平台公开 API；
- 不包含 GUI、后台常驻服务或跨设备 Token 导出功能。
