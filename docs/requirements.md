# 百度网盘 MCP 需求拆分

## 产品目标

提供一个本地优先的 C# MCP Server，让模型在用户明确授权后，以可审计、最小权限的方式读取和管理百度网盘文件。

默认边界：

- 使用百度开放平台公开 API，不模拟网页端协议；
- Token 和 Secret 不进入仓库、日志或 MCP 返回值；
- 只读能力优先，修改与删除能力必须有清晰的目标和结果；
- 首个版本以单用户、本地 `stdio` MCP Server 为目标，不要求公网域名；
- 每项需求用 1～2 个聚焦提交完成，提交必须包含相应测试或验证记录。

## R1：OAuth 授权

状态：已完成。

能力：

- 生成授权 URL；
- 授权码换取 Token；
- Refresh Token 刷新；
- 本地保存并脱敏显示 Token；
- 验证回调 `state`。

## R2：账号状态

状态：进行中。

能力：

- 获取授权用户的百度名称、网盘名称、头像、用户标识和会员类型；
- 获取网盘总容量、已用容量和剩余容量；
- 对百度业务错误返回统一异常，不泄露 Access Token；
- 提供 `account` 和 `quota` CLI 命令用于独立验收。

验收：真实授权账号调用成功；成功、业务错误和异常响应均有自动测试。

## R3：文件浏览与检索

能力：

- 分页列出目录；
- 获取文件元数据；
- 按名称搜索；
- 支持排序、分页参数和中文路径；
- 明确应用目录访问边界。

验收：目录、空目录、文件、中文和特殊字符路径都有测试。

## R4：文件下载

能力：

- 获取官方下载地址并下载到指定本地路径；
- 支持大文件流式传输、进度、取消和校验；
- 默认不覆盖现有文件。

验收：小文件和分块读取通过；中断后不会留下伪装成完整文件的结果。

## R5：文件上传

能力：

- 小文件与分片上传；
- 预创建、分片传输、最终创建的完整协议；
- 支持进度、失败重试和同名策略；
- 不把整个大文件载入内存。

验收：空文件、小文件、多分片文件及中途失败恢复均有测试。

## R6：文件管理

能力：

- 新建目录、复制、移动、重命名和删除；
- 批量操作返回逐项结果；
- 删除和覆盖属于显式操作，不做隐式降级。

验收：冲突策略、部分失败和幂等行为清晰可见。

## R7：Token 生命周期

能力：

- API 调用前按需自动刷新；
- 并发刷新只执行一次；
- 刷新后原子更新 Token 文件；
- 失效时给出重新授权指引。

验收：过期、即将过期、刷新失败及并发刷新均有测试。

## R8：MCP Server

能力：

- 通过 `stdio` 提供账号、文件查询、下载、上传和文件管理工具；
- 工具参数具备明确 JSON Schema；
- 标准输出只承载 MCP 协议，诊断信息写入标准错误；
- 对返回数量、文本长度和本地路径进行限制。

验收：MCP 初始化、工具发现、调用、错误返回和进程退出均有集成测试。

## R9：安全与发布

能力：

- Windows 凭据保护或可替换的安全 Token Store；
- 结构化日志与敏感字段清理；
- `dotnet tool` 或自包含程序发布；
- 安装、授权、配置 MCP 客户端和故障排查文档。

验收：干净环境可按文档完成安装和首次调用，发布包不包含凭据。
